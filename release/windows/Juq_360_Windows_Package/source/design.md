# Juq 모바일 인터페이스 설계

## 제품 목적

**Juq**는 사용자가 사진 또는 기본 작업 화면 위에 0°부터 360°까지의 투명한 원형 각도기를 겹쳐 놓고, 기준선과 측정선을 조절하여 각도를 빠르게 읽을 수 있게 하는 세로형 모바일 도구다. 한 손으로도 주된 측정 흐름을 완성하도록 모든 반복 제어를 화면 하단에 배치한다.

## 화면 목록

| 화면 | 주요 콘텐츠 | 주요 기능 |
|---|---|---|
| 측정 작업공간 | 배경 캔버스, 원형 360° 각도기, 중심 십자선, 기준선·측정선, 현재 각도 배지 | 배경 선택, 각도기 이동·확대, 기준선과 측정선의 각도 조절, 눈금 표시 전환 |
| 배경 선택 시트 | 카메라·사진 보관함·빈 작업면 진입 항목 | 측정 대상 사진을 선택하거나 새 사진을 촬영하고, 빈 배경으로 돌아가기 |
| 측정 제어 시트 | 기준선·측정선의 세밀 조절, 스냅 단위, 불투명도, 초기화 | 각도 측정값을 정밀하게 보정하고 각도기 표현을 조절 |
| 도움말 시트 | 3단계 사용 안내와 값의 의미 | 기본 측정 절차를 빠르게 확인 |

## 핵심 사용자 흐름

| 목적 | 흐름 |
|---|---|
| 사진 위 각도 측정 | 사용자가 **사진**을 탭함 → 이미지를 선택함 → 화면 중앙의 각도기를 목표 지점에 끌어 놓음 → 기준선과 측정선을 각각 드래그함 → 상단에 계산된 0–360° 값이 표시됨 |
| 빈 화면에서 각도 확인 | 사용자가 기본 작업공간을 엶 → 하단 슬라이더 또는 원 위 핸들을 움직임 → 측정값과 호·눈금이 갱신됨 |
| 재측정 | 사용자가 **초기화**를 탭함 → 기준선은 0°, 측정선은 45°, 중심과 크기는 기본값으로 되돌아감 |

## 레이아웃 원칙

세로 9:16 화면을 기준으로, 상단에는 뒤로가기 없는 작업 제목과 읽기 전용 각도 배지를 둔다. 중앙의 넓은 작업면은 사진 또는 중성 그리드 배경을 표시하고, 정확한 드래그를 위해 각도기 중심을 화면 중앙보다 약간 위에 배치한다. 엄지 접근이 쉬운 하단에는 배경, 제어, 초기화 순으로 세 개의 큰 원형 버튼을 고정하며, 세밀 조절은 하단 시트에서 제공한다. 최소 터치 목표는 44pt 이상으로 구성하고, 색만으로 상태를 구분하지 않는다.

## 색상 및 표현

| 역할 | 색상 | 용도 |
|---|---|---|
| 잉크 네이비 | `#0D1B2A` | 작업면 바탕과 제목 텍스트 |
| 신호 시안 | `#00C2D1` | 기준선, 활성 제어, 현재 각도 강조 |
| 안전 오렌지 | `#FF9F1C` | 측정선과 호 표시 |
| 페이퍼 화이트 | `#F7FAFC` | 제어 시트와 카드 표면 |
| 소프트 슬레이트 | `#7A8A99` | 눈금, 보조 텍스트, 비활성 요소 |

각도기는 반투명한 흰색 디스크와 또렷한 네이비 눈금을 사용한다. 기준선은 시안, 측정선은 오렌지로 구분하며, 각도 수치는 높은 대비의 네이비 배지에 표기한다. 시각적 우선순위는 **현재 측정값 → 두 기준선 → 눈금 → 부가 제어** 순서다.
